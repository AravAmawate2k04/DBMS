# Grocery Store Management System (GSMS)

Welcome to the Grocery Store Management System (GSMS), a full-stack project engineered by [AravAmawate2k04] [Shreyansh22485]
(https://github.com/AravAmawate2k04) to streamline product and order management for retail environments. This system showcases my proficiency in building database-driven web applications.

## What Does This Project Do?

GSMS enables store managers to efficiently handle products and customer orders through a user-friendly web interface, powered by a robust Python backend and a responsive frontend.

### Key Features
- **Product Management:** Add, view, and delete products with attributes like name, description, unit weight, price, supplier, and category.
- **Order Management:** Create customer orders, select products and quantities, and track costs and details.
- **Interactive UI:** Built with HTML, CSS (Bootstrap & custom styles), and JavaScript; supports tooltips, modals, and dynamic form interactions.
- **API-Driven Backend:** Python Flask server exposes RESTful endpoints for product and order operations, connected to a SQL database.

## Technical Highlights

- **Backend:** Python (Flask), MySQL
  - DAO pattern for clean database transactions.
  - Order and product insertion, retrieval, and deletion APIs.
- **Frontend:** HTML, CSS, JavaScript, jQuery
  - Modular UI for managing products/orders.
  - AJAX calls for seamless user experience.

## Getting Started

1. **Clone the repository** and set up required Python and MySQL environments.
2. **Run the backend server** (`backend/server.py`) after configuring the database.
3. **Open the UI** (`ui/index.html`) in your browser to start managing your store.

## Folder Structure

- `backend/` – Python backend (Flask, DAOs)
- `ui/` – Frontend (HTML, JS, CSS)
- `ui/js/custom/` – Custom JS for UI logic
- `ui/css/` – Style sheets
